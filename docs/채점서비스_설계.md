# aiarena 채점 서비스 설계 (초안 · 2026-09-22)

> 백준과 같은 자리: **학습은 각자 맥에서, 채점은 공짜로.**
> 백준이 서버를 공짜로 줄 수 있었던 건 채점 한 번이 1초도 안 걸려서였다.
> 우리 판도 학습은 몇 시간이지만 **채점은 몇 초**다 — 그래서 같은 구조가 선다.

## 0. 실측 근거

| 항목 | 값 |
|---|---|
| 제출 파일 크기 | 약 96KB (숫자 23,309개) |
| 채점 1회 (기준선 4종 × 50판 = 200판) | **3.6초, CPU 코어 1개** (맥북, 9/22) |
| 코어 4개 서버 하루 처리량 | 약 9만 건 |

→ 채점 서버 비용은 무시할 수준이다. 병목은 서버비가 아니라 **사람 모으기**다.

## 1. 문제(판)

백준의 "문제" = 우리 "판". 판 하나 = 엔진 버전 + 맵 + 자리 + 유닛 구성 + 판단주기.

| 문제 번호 | 이름 | 내용 |
|---|---|---|
| 1001 | 벌처 무빙샷 | 벌처 1 (제출) vs 저글링 6 (서버 기준선) |
| 1002 | 저글링 포위 | 저글링 6 (제출) vs 벌처 1 (서버 기준선) |
| 이후 | 월 1~2개 추가 | 영상에서 다룬 판을 문제로 (드라군 마인, 마린 vs 럴커 …) |

- 판은 **판 버전 해시**로 고정한다 (엔진 커밋 + 맵 SHA-256 + 옵션). 엔진을 고치면 새 해시 → 전부 **재채점** (백준 재채점과 같음).

## 2. 제출물

- **`.pt` 를 그대로 받지 않는다.** `.pt` 는 파이썬 pickle 이라 여는 순간 코드가 실행될 수 있다.
- 앱의 **"제출용 내보내기"** 버튼이 가중치만 `.npz` (numpy, `allow_pickle=False`) 로 저장한다.
- 서버는 모양만 확인한다: `39→128→128→12` 고정. 모양이 다르면 "형식 오류".
- 신경망은 숫자 계산만 하므로 **제출물이 서버에서 할 수 있는 일이 없다** — 백준보다 보안이 쉽다 (백준은 임의 코드를 돌려야 했다).

## 3. 채점

1. **예제 채점 (앱 안, 로컬)** — 공개 씨앗 20개로 기준선 4종과 붙인다. 서버와 같은 코드. 제출 전 미리보기.
2. **본 채점 (서버)** — 비공개 씨앗 200판. 행동은 argmax (확률 뽑기 아님) → **같은 파일이면 항상 같은 점수**.
   - 씨앗을 숨기는 이유 = 백준의 숨긴 테스트케이스. 공개 씨앗에만 맞춘 파일을 걸러낸다.
3. **결과 표시**

| 결과 | 조건 (1001 벌처 기준 예시) |
|---|---|
| 🟢 맞았습니다 | 무빙샷 손코딩이 내는 승률을 넘김 |
| 🟡 부분 점수 | 기준선 일부만 넘김 (점수 0~100) |
| 🔴 틀렸습니다 | 돌진 기준선도 못 넘김 |

   손코딩 무빙샷 = "사람이 짠 정답". 이걸 넘으면 AI 가 사람을 넘은 것 (채널 영상 구조 그대로).
4. **순위표** — 맞은 사람들끼리 주 1회 리그전(서로 붙이기) → 레이팅. ※ 블리자드 규정상 공식 명칭에 '리그' 사용 금지 → "랭킹전" 등으로.
5. **판 재생** — 채점한 판 중 1판을 영상(움짤)으로 남긴다. 공유용 = 트래픽 장치.

## 4. 단계별 구현

| 단계 | 내용 | 서버비 | 비고 |
|---|---|---|---|
| **0. 로컬 채점** | 앱에 "채점" 탭 + 제출용 내보내기 | 0원 | 1~2일. 서버 없이 먼저 수요 확인 |
| **1. 깃허브 채점** | 제출 = 깃허브 이슈 폼에 `.npz` 첨부 → 채점 봇이 결과 댓글 + 순위표(GitHub Pages) | 0원 | 로그인·계정 관리를 깃허브에 맡긴다. 채점 봇은 집 맥에서 상시 실행 |
| **2. 웹 채점** | aiarena 사이트 + 깃허브 로그인 + 채점 큐 + CPU 서버 1대 | 월 2~5만원 | 카카오 클라우드 크레딧 30만원 활용 가능 |

**권장: 0 → 1.** 1단계에서 제출이 주 50건을 넘으면 2단계.

- 1단계 채점을 GitHub Actions 로 돌리는 방법도 있지만(공개 저장소는 무료), Actions 약관이 "저장소 소프트웨어의 빌드·테스트" 외 용도를 제한해 회색지대다. 집 맥 봇이 안전하다.

## 6. 확인해야 할 것 (막히면 설계가 바뀜)

1. **블리자드 AI 약관**: 게임 파일을 "서버에서 남의 AI 채점에" 쓰는 것이 연구 목적에 들어가는지. 채점은 무료·비상업으로 두되, 같은 사이트에 유료 강의를 붙이는 게 괜찮은지 → **블리자드에 문의 메일** 권장.
2. **OpenBW 라이선스**: 서버에서 돌리기만 하는 건 배포가 아니라 문제 적음. 앱 배포 쪽 확인은 따로.
3. **악용**: 같은 파일 재제출 → 파일 해시로 중복 차단. 하루 제출 횟수 제한 (예: 문제당 10회).
