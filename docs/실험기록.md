# 실험 기록 — 이 판에서 실제로 해본 것

성공한 방법만 적으면 따라 하는 사람이 같은 데서 넘어진다. **실패한 것도 같이 적는다.**

전부 맥북 한 대, GPU 없이, 각각 몇 분 안에 나온 결과다.

---

```

                          돌진      무빙샷     벌리기        합계
  손코딩 돌진             0:24      0:24      5:19        5/72    6.9%
  손코딩 무빙샷          21:3      23:1       9:15       53/72   73.6%
  손코딩 벌리기           0:24      0:24      9:15        9/72   12.5%
  ── 학습 ──
  한 상대만 보고 배움      0:24      0:24     24:0        24/72   33.3%
  맨땅 PPO (상대 섞음)    0:24      0:20     22:0        22/72   30.6%
  베낀 망                21:3      23:1      9:15       53/72   73.6%
  ★ 베끼기 + 이어서 PPO   23:1      23:1     24:0        70/72   97.2%
```

직접 뽑아보려면:

```bash
python tools/compare.py runs/clone_ft/best.pt --label 내망
```

## 1. 손으로 고치면 대개 나빠진다

무빙샷 봇에 두 가지를 해봤다. 96판 기준 승수다.

| 고친 것 | 결과 |
|---|---|
| 그대로 | 58 |
| 공격 행동을 `9`(가장 가까운 적) → `10`(체력 적은 적) — **한 줄** | **61** ↑ |
| 거기에 "벽에 몰리지 않게 맵 중앙 쪽으로 물러나기" 추가 | **1** ↓↓↓ |

두 번째는 진단이 멀쩡했다. 실제로 무빙샷 봇은 벽에 몰려 죽는다.
그런데 적 반대 방향과 중앙 방향이 서로 당겨서 갈팡질팡하다 그냥 죽었다.

**직관은 자주 틀리고, 표는 2초 만에 알려준다.** 이 판의 첫 번째 쓸모다.

## 2. 맨땅에서 배우면 "제일 쉬운 하나"에 눌러앉는다

```bash
python -m aiarena.train.ppo --foe spread --updates 400
```

목표로 삼은 상대(벌리기)는 **24:0 으로 완승**했다. 손코딩 최고가 9:15 였으니 크게 넘은 셈이다.

그런데 다른 상대에게 붙여보니:

```
              돌진    무빙샷   벌리기
한 상대 전용   0:24    0:24    24:0     → 총점 33.3%
손코딩 무빙샷  21:3    23:1     9:15    → 총점 73.6%
```

**제일 쉬운 상대 둘한테 전패다.** 이기는 법이 아니라 그 상대의 움직임을 외운 것이다.

### 상대를 섞어도 안 풀렸다

`--foe mixed` 로 판마다 상대를 갈아줬다. 결과는 **30.6%** — 거의 같았다.
표를 보면 여전히 벌리기만 22:0 이고 나머지는 전패다.
상대를 섞는 것만으로는 부족하다. 점수를 제일 쉽게 딸 수 있는 곳에 그대로 눌러앉는다.

## 3. 베끼면 약점까지 똑같이 물려받는다

```bash
python -m aiarena.train.clone --teacher kite
```

30초면 끝난다. 그리고 선생과 성적이 **한 칸도 안 틀린다.**

```
          돌진    무빙샷   벌리기
선생      21:3    23:1     9:15
베낀 망   21:3    23:1     9:15
```

잘하는 것만 물려받는 게 아니다. **못하는 것(벌리기 9:15)도 그대로다.**
베끼기는 출발점이지 답이 아니다.

## 4. 베끼고 이어서 배우면 선생을 넘는다 — 단 한 번 무너진다

```bash
python -m aiarena.train.ppo --foe mixed --init runs/clone/cloned.pt --lr 1e-4
```

평가 곡선이 이랬다:

```
73.6%  ← 베낀 망에서 출발
54.2%  ← 먼저 나빠진다
75.0%  ← 선생을 살짝 넘음
 2.8%  ← ★ 무너진다
30.6%
97.2%  ← 되돌아와서 선생을 크게 넘음
95.8% · 94.4% · 93.1%  ← 이제 안정적
```

최종적으로 **선생의 약점이던 벌리기를 9:15 → 24:0 으로 풀었다.**

### 여기서 꼭 알아야 할 것

**① 마지막 값으로 판단하면 안 된다.**
2.8% 지점에서 껐으면 "이어학습은 안 되는구나"로 끝났을 것이다.
`best.pt` 를 따로 저장하는 이유가 이것이다.

**② 학습 로그의 승률은 실력이 아니다.**
학습 중 찍히는 승률은 일부러 흔들어 뽑은 값이라 실제보다 낮게 나온다.
실력은 `--eval-every` 가 따로 재는 숫자로 본다.

**③ 이웃한 지점끼리 크게 튄다.**
75% 다음이 2.8% 다. 한 점을 보고 "넘었다/망했다"를 말하면 안 되고,
몇 번의 평가를 창으로 봐야 한다.

**④ 값머리를 예열하지 않으면 시작하자마자 망가진다.**
베끼기는 정책만 가르치므로 '앞으로 딸 점수 예상'이 백지로 남는다.
그대로 PPO 를 시작하면 엉터리 되돌림 값을 따라 정책이 폭주한다.
`train/clone.py` 의 `warm_value()` 가 정책을 얼려두고 값머리만 먼저 맞추는 단계다.

**⑤ 베끼고 나면 탐험이 거의 죽어 있다.**
엔트로피가 0.16~0.28 까지 떨어진다 (균등이면 2.48).
새로운 수를 거의 시도하지 않는다는 뜻이다. 더 좋은 답이 딴 데 있어도 못 찾을 수 있다.
