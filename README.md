# aiarena

유닛 컨트롤 AI를 붙여보는 판. 게임이 없어도 돌아간다.

> **영상 보고 오셨나요?** 영상에 나온 학습을 그대로 따라 하려면 원래 게임을 사고,
> 옛날 버전을 맞추고, 빌드를 통과해야 합니다. 거기서 대부분 막힙니다.
> 그래서 **싸우는 판만 떼어내 다시 만들었습니다.** 게임 없이, 3분이면 돌아갑니다.

```bash
git clone <이 저장소>
cd aiarena
pip install numpy
python tools/crosstable.py
```

**3분이면 첫 결과가 나온다.** 게임을 사지 않아도, 설치할 것도 없다.

## 뭘 하는 건가

사거리가 긴 유닛 1기(**raider**)와 근접 유닛 6마리(**biter**)를 붙인다.
raider 는 혼자지만 5배 멀리서 쏘고 조금 더 빠르다. biter 는 느리지만 여섯이고 쿨다운이 짧다.

혼자서 여섯을 이기려면 **쏘고 물러나기**를 할 줄 알아야 한다. 서서 맞으면 죽고,
도망만 다니면 시간이 끝난다.

봇 넷이 기본으로 들어 있다. 전부 붙여보면 이런 표가 나온다:

```
  P0 \ P1        정지      돌진     무빙샷     벌리기
  정지          0:0 *     0:24     0:24      0:24
  돌진          0:24      0:24     0:24      3:21
  무빙샷         8:16     19:5     21:3      10:14
  벌리기         0:24      0:24     0:24      6:18
```

무빙샷만 이긴다. 나머지는 전멸한다.

## 내 봇 만들기

`bots/example/bot.py` 를 복사해서 고치면 된다. 계약은 함수 하나뿐이다.

```python
def act(obs, mask):
    """obs  : (유닛 수, 39) 숫자판. 죽은 유닛 줄은 전부 0
       mask : 살아 있으면 1
       반환 : 유닛마다 행동 번호 하나 (0~11)"""
    return [9] * len(obs)      # 전원 "가장 가까운 적 공격"
```

강화학습이든 if 문 덩어리든 상관없다. **이 함수만 있으면 된다.**

### 행동 12가지

| 번호 | 뜻 |
|---|---|
| 0 | 명령 없음 — 알아서 적을 찾아 싸운다 |
| 1~8 | 8방향으로 이동 |
| 9 | 가장 가까운 적을 쏜다 |
| 10 | 체력이 가장 적은 적을 쏜다 |
| 11 | 가장 가까운 적의 반대로 물러난다 |

사거리 밖에서 9나 10을 내면 **헛방**이다. 그 판단은 버려진다.

### 관측 39칸

| 칸 | 뜻 |
|---|---|
| 0 | 내 체력 비율 |
| 1 | 내 쿨다운 비율 (**0이면 지금 쏠 수 있다**) |
| 2 | 살아 있음 |
| 3~4 | 내 위치 (맵 중앙 기준) |
| 5~22 | 가까운 적 3기 — 각 6칸: 상대 x, 상대 y, 거리, 체력비, 있음, **사거리 안** |
| 23~38 | 아군 4기 — 각 4칸: 상대 x, 상대 y, 체력비, 있음 |

위치와 거리는 256으로, 내 위치는 512로 나눠져 있다. 픽셀로 보려면 곱하면 된다.

## 학습시키기

손으로 짠 봇은 금방 한계가 온다. 직관이 자주 틀리기 때문이다.
여기서부터는 **점수만 주고 나머지는 맡긴다.**

```bash
pip install torch
python -m aiarena.train.ppo --foe spread --updates 400
```

싸우는 법은 한 줄도 안 알려준다. 점수가 높은 행동만 남는 것뿐이다.

### 점수표가 성격을 만든다

`aiarena/core/reward.py` 가 이 판에서 **유일하게 창작인 자리**다.

| 항목 | 기본값 | 올리면 |
|---|---|---|
| `enemy_hp` | 3.0 | 적 체력을 깎으러 달려든다 |
| `ally_hp` | 0.3 | 제 몸을 사린다 |
| `kill` / `death` | 2.0 / 1.0 | 마무리를 챙긴다 / 죽는 걸 무서워한다 |
| `win` / `lose` | 10.0 | 끝을 본다 |
| **`timeout`** | **25.0** | ★ **낮추면 "안 싸우고 버티기"가 최적해가 된다** |
| `step` | 0.001 | 조급해진다 |

미리 만들어둔 점수표로 성격을 비교해볼 수 있다:

```bash
python -m aiarena.train.ppo --reward 겁쟁이     # 내 몸 사리기
python -m aiarena.train.ppo --reward 돌격대     # 내 피해를 안 센다
python -m aiarena.train.ppo --reward 속전속결   # 빨리 끝내라
```

같은 판, 같은 코드인데 **완전히 다르게 싸운다.** 이게 이 판의 본론이다.

### 지금 최고 기록

| | 총점 (72판) |
|---|---|
| 손코딩 최고 (무빙샷) | 53 · **73.6%** |
| **학습 최고** | **70 · 97.2%** |

맨땅에서 배우면 오히려 **30.6%** 밖에 안 나온다. 한 상대만 외워버리기 때문이다.
무엇이 되고 무엇이 안 됐는지는 [실험 기록](docs/실험기록.md)에 실패까지 그대로 적어뒀다.
따라 하다 같은 데서 넘어지지 않게.

```bash
python -m aiarena.train.clone --teacher kite          # 먼저 베끼고 (30초)
python -m aiarena.train.ppo --foe mixed \
       --init runs/clone/cloned.pt --lr 1e-4          # 이어서 배운다
python tools/compare.py runs/clone_ft/best.pt         # 기준선과 나란히 본다
```

### 학습한 망을 봇으로 내기

계약이 같아서 그대로 쓸 수 있다.

```python
import torch
from aiarena.train.ppo import Policy, make_bot

p = Policy(); p.load_state_dict(torch.load("runs/ppo/best.pt")["model"])
act = make_bot(p)        # 이게 바로 봇이다
```

## 판을 새로 만들려면

`aiarena/core/spec.py` 의 `UNITS` 와 `SCENARIOS` 에 줄을 더하면 된다. 코드는 안 건드린다.

```python
UNITS["brute"] = UnitSpec(name="brute", hp=200, damage=30, cooldown=22,
                          range=15, speed=4.0, size=24)
SCENARIOS["raider_vs_brute"] = ScenarioSpec(key="raider_vs_brute",
                                            p0_unit="raider", p0_count=3,
                                            p1_unit="brute",  p1_count=2)
```

단 **판을 하나 더할 때마다 `expected.md` 를 같이 쓴다.** 기본 봇 4종 대전표와,
그중 40~60% 사이인 칸이 어디인지. 그 칸이 없으면 실력이 승부를 못 가르는 판이라
아무리 잘 만든 봇도 의미가 없다.

## 왜 게임이 필요 없나

원래 이 판은 실제 게임 엔진 위에서 굴렸다. 그런데 그러면 게임을 사야 하고,
버전을 맞춰야 하고, 되기까지 몇 시간이 걸린다. 그래서 **물리만 떼어내서 다시 만들었다.**

유닛 수치는 원본 게임 데이터에서 그대로 읽어왔다 — 체력, 공격력, 쿨다운, 사거리,
속도, 가속도, 선회 속도, 충돌 박스, 시야까지. 이름과 그림만 없다.

제대로 옮겼는지는 **대전표로 채점했다.** 원본에서 뽑은 손코딩 4종 대전표와
여기서 나온 표를 비교해서, 15칸 평균 오차 13%p 까지 맞췄다.
어디가 아직 다르고 왜 그런지는 [expected.md](aiarena/scenarios/raider_vs_biter/expected.md) 에 적어뒀다.
