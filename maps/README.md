# 맵

`Fighting_Spirit_1.3.scx` — 투혼 1.3 (128×128, 제작 Rose.of.Dream, 래더 표준판).
출처: https://scmscx.com/map/zgG834gf

판은 맵 한가운데가 아니라 **7시 방향 열린 흙바닥(x 1280, y 2560)** 에서 선다.
한가운데는 구조물에 둘러싸여 벌처가 뺄 자리가 없다.
자리를 바꾸려면 `SC_SPOT=x,y` 환경변수를 주면 된다 (픽셀 단위, 타일 1칸 = 32).

자리별 손코딩 실측 (벌처 무빙샷 vs 저글링 돌진, 60판):

| 자리 | 벌처 : 저글링 |
|---|---|
| **1280, 2560 (채택)** | **32 : 27** |
| 1792, 2816 | 42 : 17 |
| 2048, 3072 | 51 : 9 |
| 2048, 2048 (한가운데) | 39 : 21 |
