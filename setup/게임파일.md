# 게임 파일 준비

이 저장소에는 게임 파일이 들어 있지 않습니다. 블리자드 소유라서 다시 배포할 수 없습니다.

대신 **블리자드가 AI 연구용으로 게임 파일을 공식 배포**하고 있습니다. 한 줄이면 받습니다:

```bash
bash setup/get_mpq.sh
```

블리자드 서버(`download.blizzard.com/pub/ai/`)에서 받아서, 약관을 화면에 보여주고,
동의하면 `data/mpq/` 에 세 파일을 풀어둡니다.

| 파일 | 크기 |
|---|---|
| `StarDat.mpq` | 약 64MB |
| `BrooDat.mpq` | 약 21MB |
| `patch_rt.mpq` | 약 2MB |

## 약관 요점 (Blizzard StarCraft AI and Machine Learning EULA)

- **AI 테스트, 머신러닝, 관련 연구 목적으로만** 쓸 수 있습니다
- 일반 약관에 있는 **자동화(봇) 금지가 이 파일에는 적용되지 않습니다** — AI 가 게임을 조작해도 됩니다
- 학습으로 나온 데이터·모델은 본인 것입니다
- 게임 파일 자체를 **상업적으로 이용하거나 다시 배포하면 안 됩니다**
- 블리자드 계정은 필요 없습니다

전문은 받은 패키지 안의 `Blizzard AI and Machine Learning EULA.txt` 에 있습니다.

## ★ 지금 파는·무료로 받는 스타크래프트에서는 안 됩니다

리마스터(2017) 이후 스타크래프트는 게임 파일을 다른 형식(CASC)으로 바꿔서,
`StarDat.mpq`·`BrooDat.mpq` 가 더 이상 들어 있지 않습니다.
OpenBW 는 예전 형식의 MPQ 만 읽기 때문에, 위의 **AI 연구용 패키지**를 받아야 합니다.

## 왜 파일을 안 주나요

`data/mpq/` 안에 게임의 거의 전부가 들어 있습니다 — 유닛 그림, 소리, 맵 타일,
그리고 **유닛 수치까지**요. 벌처 체력이 80이고 사거리가 160픽셀이라는 것도
엔진 코드가 아니라 이 파일에 적혀 있습니다. 엔진(OpenBW)은 오픈소스지만 이 내용물은
블리자드 것이고, 약관상 각자 블리자드에서 직접 받아야 합니다.

## 잘 안 될 때

**`failed to open Patch_rt.mpq`**
→ 파일이 `data/mpq/` 에 없습니다. `bash setup/get_mpq.sh` 를 다시 돌려보세요.

**`sdl2-config: command not found`**
→ SDL2 가 없습니다.
`brew install sdl2 sdl2_mixer sdl2_image` (macOS) /
`sudo apt install libsdl2-dev libsdl2-mixer-dev libsdl2-image-dev` (Ubuntu)

**빌드는 됐는데 화면이 안 뜬다**
→ 학습 중에는 화면을 그리지 않습니다. 정상입니다.
