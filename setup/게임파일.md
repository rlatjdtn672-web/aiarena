# 게임 파일 준비

이 저장소에는 게임 파일이 들어 있지 않습니다. 블리자드 소유라서 배포할 수 없습니다.
대신 **원작 스타크래프트는 무료**라서, 직접 받아 복사하시면 됩니다.

## 1. 스타크래프트 받기 (무료)

블리자드가 2017년 3월에 **스타크래프트 앤솔로지(원작 + 브루드워)를 무료로 풀었습니다.**
Battle.net 공식 런처에서 받으시면 됩니다. 유료인 건 리마스터(HD 그래픽)뿐이고,
이 저장소는 무료판으로 충분히 돌아갑니다.

> 리마스터를 이미 갖고 계시면 그걸 쓰셔도 됩니다. 필요한 파일은 같습니다.

## 2. 파일 세 개 찾기

설치 폴더에서 이 셋을 찾습니다.

| 파일 | 크기 |
|---|---|
| `StarDat.mpq` | 약 63MB |
| `BrooDat.mpq` | 약 20MB |
| `patch_rt.mpq` | 약 1MB |

설치 위치 (기본값):

- **Windows** — `C:\Program Files (x86)\StarCraft\`
- **macOS** — `/Applications/StarCraft/` 안쪽
  (`StarCraft.app` 을 마우스 오른쪽 → "패키지 내용 보기" 로 들어가야 할 수도 있습니다)

찾기 어려우면 파일 이름으로 검색하세요. 이름이 정확히 위와 같습니다.

## 3. 복사하기

```bash
cp /경로/StarDat.mpq  /경로/BrooDat.mpq  /경로/patch_rt.mpq  data/mpq/
```

넣고 나면 이렇게 됩니다:

```
data/mpq/
├── StarDat.mpq
├── BrooDat.mpq
└── patch_rt.mpq
```

끝입니다. 이제 학습을 돌릴 수 있습니다.

---

## 왜 파일을 안 주나요

`data/mpq/` 안에 게임의 거의 전부가 들어 있습니다 — 유닛 그림, 소리, 맵 타일,
그리고 **유닛 수치까지**요. 벌처 체력이 80이고 사거리가 160픽셀이라는 것도
엔진 코드가 아니라 이 파일에 적혀 있습니다.

엔진(OpenBW)은 오픈소스지만 이 내용물은 블리자드 것입니다. 그래서 각자 자기 게임에서
가져오는 방식으로 씁니다. BWAPI, SSCAIT 같은 스타크래프트 AI 프로젝트들이
15년 넘게 이렇게 해왔습니다.

## 잘 안 될 때

**`failed to open Patch_rt.mpq`**
→ 파일이 `data/mpq/` 에 없습니다. 이름 철자와 위치를 확인하세요.

**`sdl2-config: command not found`**
→ SDL2 가 없습니다.
`brew install sdl2 sdl2_mixer sdl2_image` (macOS) /
`sudo apt install libsdl2-dev libsdl2-mixer-dev libsdl2-image-dev` (Ubuntu)

**빌드는 됐는데 화면이 안 뜬다**
→ 학습 중에는 화면을 그리지 않습니다. 정상입니다.
